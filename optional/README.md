# Optional add-ons

## Pine Script (TradingView)

Tomas đã chọn **có làm Pine** — nhưng **sau Phase 6**.

Pine Script là ngôn ngữ của TradingView để viết chỉ báo / chiến lược chạy **trên chart TV**. Không thay bot Python; dùng để soi logic trên TV sau khi engine Python ổn.

Thư mục này sẽ chứa port Pine khi tới giai đoạn đó. **Phase 1–6 không cần file Pine.**
